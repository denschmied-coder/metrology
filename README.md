# metrology
Программа для учета средств измерений (Java, Spring Boot)

Программа служит для учета средств измерений в базе данных PostgreSQL.
Программа может осуществлять следующие функции: добавление средства измерения(далее СИ), удаление СИ, редактирование СИ, поиск СИ по различным критериям, вывод на экран всех СИ с сортировкой, вывод на экран найденных СИ, сохранение в файл СИ для поверки и ТО с подходящей датой поверки.

Также программа содержит блок кода для обмена информацией с программой клиентом в формате json. Здесь также будут доступны функции:
1. Получение данных с сортировкой по типам средств измерений;
2. Получение данных с сортировкой по датам следующей поверки;
3. Получение данных по идентификационному номеру;
4. Внесение в базу нового средства измерений;
5. Корректировка средства измерений;
6. Удаление по идентификационному номеру;
7. Получение объектов с приближающейся  датой калибровки и сохранение в текстовый файл.
